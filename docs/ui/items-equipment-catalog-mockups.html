Mockup 2

Preview Modal Composition

The preview becomes the rich read surface, with card-safe metadata up top and parsed subtype details below.

Longsword

Weapon / Martial Melee · Read-only SRD item

Value15 gp Weight3 lb Damage1d8 Range5 ft
Slashing Versatile Mastery: Sap Two-handed 1d10

Weapon Details

  • Martial melee weapon.
  • Versatile damage: 1d10 slashing.
  • Mastery appears only when enriched source data is present.

Inventory Hooks

  • Can be equipped, carried, dropped, awarded, or sold.
  • Future loot rewards can clone this into a player inventory stack.

Description

A standard one-handed blade. The preview keeps description and rule text readable while the card stays compact.

Collapsed Source Metadata

Source payload is hidden by default and available for import validation only.

Thieves' Tools

Tool / Other Tools · SRD enrichment target

Value25 gp Weight1 lb AbilityDex UseLocks

Tool Details

  • Utilize: pick a lock or disarm a trap when source data supports it.
  • Craft: show craftable outputs when available.
  • Variants: render as chips or a compact list.

SRD 2014 Fallback

If ability, utilize, craft, or variants are missing, omit those chips and show the standard description.
